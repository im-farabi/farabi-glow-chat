
# Fix APIFree Image Models - Complete Overhaul

## Issues Identified

### 1. GPT Image 1.5 & Nano Banana Pro - Broken Image Display
The API successfully returns an image URL (confirmed in logs: `Success! Image URL: https://static.apifree.ai/files/image/...`), but the image shows broken with alt text "Generated by GPT Image 1.5".

**Root Cause:** The returned image URL might be a temporary URL that requires authentication, or CORS is blocking the image load. The frontend receives the URL but cannot display it.

**Solution:** Proxy the image through our edge function - fetch the image, convert to base64, and return as a data URL that the frontend can display without CORS issues.

---

### 2. FLUX 2 DEV, Qwen Image, Z Image Turbo - Wrong API Parameters
The logs show errors like:
- `数据格式异常` (data format exception)  
- `Submit failed with code 400100`

**Root Cause:** The `buildPayload` function incorrectly sends `aspect_ratio: "1:1"` for these models, but per the API docs they require:
- `width: 1024`
- `height: 1024`
- `num_inference_steps` (28 for FLUX, 50 for Qwen, 8 for Z-Image)
- `num_images: 1`

---

### 3. Rate Limiting (429 Errors)
The logs show: `"max_concurrency_exceeded"` errors.

**Solution:** Add key rotation with fallback - try all 3 API keys in sequence before giving up.

#### 2. Add API Key Rotation with Fallback

```typescript
function getAllApiKeys(): string[] {
  return [
    Deno.env.get('APIFREE_API_KEY_1'),
    Deno.env.get('APIFREE_API_KEY_2'),
    Deno.env.get('APIFREE_API_KEY_3'),
  ].filter(Boolean) as string[];
}

function shuffle<T>(arr: T[]): T[] {
  const result = [...arr];
  for (let i = result.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [result[i], result[j]] = [result[j], result[i]];
  }
  return result;
}

// In main handler: try all keys before failing
const keys = shuffle(getAllApiKeys());
let lastError = null;

for (const apiKey of keys) {
  try {
    const result = await generateImage(apiKey, model, prompt, options);
    return successResponse(result);
  } catch (error) {
    lastError = error;
    const errMsg = error instanceof Error ? error.message : '';
    // Only retry on rate limit errors
    if (errMsg.includes('429') || errMsg.includes('concurrency') || errMsg.includes('rate')) {
      console.log(`[APIFree] Key rate limited, trying next...`);
      continue;
    }
    throw error; // Don't retry other errors
  }
}
throw lastError;
```

#### 3. Proxy Image to Fix CORS/Display Issues

After getting the image URL, fetch the image and return as base64:

```typescript
// After success
const imageUrl = imageList[0];

// Fetch the image to proxy it
const imageResponse = await fetch(imageUrl);
if (!imageResponse.ok) {
  throw new Error('Failed to fetch generated image');
}

const imageArrayBuffer = await imageResponse.arrayBuffer();
const base64 = btoa(String.fromCharCode(...new Uint8Array(imageArrayBuffer)));
const contentType = imageResponse.headers.get('content-type') || 'image/png';
const dataUrl = `data:${contentType};base64,${base64}`;

return {
  imageUrl: dataUrl, // Return data URL instead of external URL
  usage: resultData.resp_data?.usage
};
```
